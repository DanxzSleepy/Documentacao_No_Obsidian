## Instruções

**Automatizando um sistema de registro de clientes**

## Visão geral

Nesta tarefa, você trabalhará na automação de um sistema de registro de clientes usando HTML, CSS e JavaScript. Este projeto ajudará você a entender como criar uma interface amigável e implementar funcionalidades que permitam aos usuários se registrarem com eficiência.

## Objectivos 🎯

Ao final desta tarefa, você deve ser capaz de:

* Crie um formulário de inscrição visualmente atraente usando HTML e CSS.
* Implemente a validação do lado do cliente usando JavaScript.
* Entenda como lidar com a entrada do usuário e fornecer feedback.

## Instruções

### Etapa 1: Configurando seu projeto ⚙️

1.  **Crie uma nova pasta:** Comece criando uma nova pasta em seu computador onde você armazenará todos os arquivos do seu projeto. Nomeie-o como "CustomerRegistrationSystem".
2.  **Criar arquivo HTML:** Dentro da pasta do seu projeto, crie um novo arquivo chamado **'index.html'**. Este arquivo conterá a estrutura do seu formulário de inscrição.
3.  **Criar arquivo CSS:** Em seguida, crie um arquivo chamado **'styles.css'** na mesma pasta. Este arquivo será usado para estilizar seu formulário de inscrição.
4.  **Criar arquivo JavaScript:** Por fim, crie um arquivo chamado **'script.js'**. Este arquivo conterá o código JavaScript que tratará da validação e envio do formulário.

### Etapa 2: Projetando o formulário de inscrição ✏️

1.  **Abra 'index.html'**: Use um editor de texto (como Bloco de Notas, Visual Studio Code ou qualquer outro editor de código) para abrir seu arquivo **'index.html'**.
2.  **Estrutura Básica**: Comece escrevendo a estrutura HTML básica. Certifique-se de incluir as tags **`.`**, **` `** e **` `**.
3.  **Criação de formulário**: Dentro da tag **` `**, crie um elemento **` `**. Este formulário deve incluir os seguintes campos:
    * **Nome**: Uma entrada de texto para o nome do usuário.
    * **E-mail**: uma entrada de texto para o endereço de e-mail do usuário.
    * **Senha**: Uma entrada de senha para a senha do usuário.
    * **Confirmar senha**: Uma entrada de senha para confirmar a senha do usuário.
    * **Botão Enviar**: Um botão para enviar o formulário.
4.  **Rotulagem**: Certifique-se de adicionar elementos **` `** para cada campo de entrada para melhorar a acessibilidade e a experiência do usuário.

### Etapa 3: Estilizar o formulário 🎨

1.  **Link CSS File**: Na seção **` `** do seu **'index.html'**, vincule seu arquivo **'styles.css'** usando a tag **` `**.
2.  **Abra 'styles.css'**: Abra seu arquivo **'styles.css'** e comece a adicionar estilos para tornar seu formulário atraente. Considere o seguinte:
    * Defina uma cor de fundo para o formulário.
    * Estilize os campos de entrada (por exemplo, preenchimento, borda, tamanho da fonte).
    * Estilize o botão de envio (por exemplo, cor de fundo, efeitos de foco).
    * Use margens e preenchimento para espaçar bem os elementos.
