## **Instruções**

# **Atividade – Automação de Testes da Aplicação da PI**

### 🎯 **Objetivo**

Os alunos deverão demonstrar que sabem aplicar **boas práticas de automação de testes** na aplicação desenvolvida para o Projeto Integrador, apresentando **testes funcionais automatizados**, **pipeline de execução**, **relatórios** e **documentação do processo**.

# 📌 **Entrega da Atividade**

Cada grupo deverá entregar **um pacote completo**, contendo:

## **1️⃣ – Conjunto mínimo de testes automatizados**

O grupo deve escolher a ferramenta adequada ao seu projeto (ex.: Cypress, Selenium, Jest, PyTest, JUnit, Playwrite etc.) e criar **ao menos 5 testes automatizados**, contemplando:

- **Testes de fluxo principal** da aplicação (ex.: login, cadastro, compra, cálculo, envio de formulário);
- Testes com **assertivas claras**;
- Uso de **boas práticas de automação**, como:
    - Page Object Model (POM), se aplicável;
    - Padronização de pastas;
    - Nomes descritivos para testes e funções;
    - Dados de teste isolados;
    - Scripts de execução automatizada (ex.: npm test, pytest, mvn test).

## **2️⃣ – Evidências por meio de Relatórios de teste**

O grupo deve gerar e apresentar:

- **Relatório automatizado** (ex.: Mochawesome, Allure, JUnit report, HTML report);
- Prints automáticos ou vídeos de execução (caso a ferramenta permita);
- Breve explicação interpretando o relatório.

## **3️⃣ – Integração com pipeline (opcional)**

Como o grupo utiliza GitHub, GitLab ou Azure DevOps, vocês precisarão configurar:

- Pipeline que execute os testes automaticamente a cada push;
- Badge de status (ex.: Build Passing);

## **4️⃣ – Demonstração oral (apresentação)**

Cada grupo deverá apresentar:

1. Estrutura do projeto de testes;
2. Como os testes são executados;
3. Onde estão as boas práticas implementadas;
4. Execução ao vivo ou gravação da suíte de testes;
5. Explicação do relatório final.

## **5️⃣ – Documentação**

O grupo deverá entregar um pequeno documento descrevendo:

- Ferramenta escolhida e justificativa;
- Estratégia de testes utilizada;
- Lista dos testes criados;
- Como executar a suíte (passo a passo).

Pode ser entregue como um **README.md no repositório, tela gravada**.
